# Distill Intelligence – analiza platforme

Detaljna analiza platforme [Distill Intelligence](https://www.distillintelligence.com/), koja prati kompanije kroz vijesti, njihove sajtove i LinkedIn.

## Sadržaj projekta

- mapa velikih cjelina platforme
- detaljan research funkcionalnosti
- tehnička dokumentacija sa dijagramima
- analiza arhitekture uz pomoć alata REA
- agent koji svaki dan šalje izvještaj o napretku na Telegram

Projekat je u izradi.
